# 제품 백로그

현재 문서는 `v1.0.0` 종료 시점 기준이다.

## 제품 방향

이 앱은 마케터용 SEO 툴이 아니라, 네이버 블로그를 운영하는 가족가 매일 부담 없이 확인하는 블로그 생활 비서다.

핵심 가치는 아래 세 가지다.

1. 오늘 봐야 할 키워드를 한눈에 보여준다.
2. 내 글이 실제 네이버 화면에서 어디에 보이는지 확인하게 해준다.
3. 다음에 어떤 글을 쓰면 좋을지 부담 없이 제안한다.

## 현재 완료된 기능

1. 키워드 직접 순위 조회
2. PC 통합검색, 모바일 통합검색, PC 블로그탭, 모바일 블로그탭, 네이버 블로그 섹션 분리
3. 기준별 상위 블로그 글 조회
4. 실제 네이버 결과 화면 URL 제공
5. 관심 키워드 저장/삭제
6. 관심 키워드 자동 순위 확인 스크립트
7. 관심 키워드 최신 순위 대시보드
8. 키워드별 최근 순위 변화
9. 오늘 요약
10. SQLite 이력 저장
11. Oracle VM 배포용 systemd 템플릿
12. 내 글 관리 MVP
13. 앱 안 알림 MVP
14. 상위글 제목 분석 MVP
15. 키워드 기회 발견 MVP
16. 발행 전 본문 분석 코치 MVP
17. 발행 전 분석의 상위글 제목/요약 기반 누락 후보
18. 내 글 메타데이터 DB 보강과 `/api/posts` 표준 API
19. 내 블로그 공개 글 일괄 가져오기와 새 글 스케줄 insert
20. 발행 전 분석의 내 글 내부 링크 후보와 기존 글 중복 확인

내 글 관리 MVP 범위:

1. 글 URL 저장
2. 글별 목표 키워드 저장
3. 글 URL 기준 순위 확인
4. 글별 최신 순위 표시
5. 글 삭제
6. 카테고리, 발행일, 글 요약 저장
7. 네이버 URL 기반 블로그 ID와 글 번호 저장
8. 글 수정과 목표 키워드 추가/삭제 API
9. 설정된 내 블로그 공개 글 가져오기
10. 스케줄 실행 시 기존 글은 건너뛰고 새 글만 insert

앱 안 알림 MVP 범위:

1. 관심 키워드 변화 기반 새 소식 표시
2. 순위 상승, 하락, 진입, 이탈 구분
3. 새 소식 클릭 시 키워드 상세 확인

상위글 제목 분석 MVP 범위:

1. 기준별 상위글 조회 결과의 제목 분석
2. 자주 보이는 단어 표시
3. 예시 제목 일부 표시

키워드 기회 발견 MVP 범위:

1. 상위글 제목의 반복 단어를 기반으로 후보 생성
2. 입력 키워드 뒤에 반복 단어를 붙인 롱테일 제안
3. 후보 클릭 시 바로 순위 확인

발행 전 본문 분석 코치 MVP 범위:

1. 키워드, 제목, 본문 입력
2. 내부 프록시 점수와 항목별 개선 제안
3. 검색 의도, 제목/첫문단, 구조, 관련어, 경험/신뢰, 독자 기대 정보 누락, 위험 요소 점검
4. 제목 후보와 소제목 후보 제안
5. 키워드 도배, 과장 표현, 중복 문장 등 위험 경고
6. 기준별 상위글 보기 결과의 제목/요약을 이용한 누락 후보 연결
7. 가져온 내 글 DB 기반 내부 링크 후보
8. 동일/유사 목표 키워드와 본문 주제 중복 확인

## v1.0.0 종료 판단

현재 버전에서 마감으로 본 범위:

1. 로컬 PC/노트북에서 clone 후 `.env`와 SQLite DB만 옮기면 바로 실행 가능
2. 순위 확인, 상위글 조회, 내 글 가져오기, 발행 전 분석, AI 보강 분석까지 한 앱에서 사용 가능
3. Discord 봇, 웹앱, 선택적 watch-ranker까지 로컬 운영 가능

## v1.1+ 후보 백로그

### 1. 화면 정보 구조 정리

현재 기능이 늘어나면서 한 화면에 정보가 많아졌다.

개선 방향:

1. 첫 화면은 `오늘 요약`, `지금 검색`, `관심 키워드`만 우선 보여준다.
2. `최근 순위 변화`, `기준별 상위글`, `최근 저장 이력`은 사용자가 눌렀을 때 펼쳐진다.
3. 키워드 하나를 선택하면 해당 키워드 상세 화면처럼 보이게 한다.

목표:

```text
앱 열기
-> 오늘 뭐가 바뀌었는지 확인
-> 필요한 키워드만 눌러서 상세 확인
```

### 2. 내 글 관리 고도화

기본 글 저장과 글 URL 기준 순위 확인은 구현됐다. 수동 입력은 제거했고, 설정된 내 블로그 공개 글 가져오기가 기본 흐름이다.

다음 단계는 글별 관리 화면을 더 편하게 만드는 것이다.

예:

```text
글: 서촌 카페 스태픽스 후기
목표 키워드:
- 서촌 카페
- 서촌 데이트 카페
- 스태픽스
- 서촌 주차 카페
```

필요 기능:

1. 저장한 글의 목표 키워드 추가/삭제 UI
2. 글별 결과 화면 URL 더 잘 드러내기
3. 순위가 오른 키워드와 떨어진 키워드 구분
4. 글별 상세 화면
5. 자동 순위 확인에 글별 키워드 포함

### 3. 키워드 기회 발견 고도화

상위글 제목 기반 롱테일 후보 제안 MVP는 구현됐다.

다음 단계는 더 다양한 신호를 섞어 후보 품질을 높이는 것이다.

외부 유료 도구 연동 없이, 네이버 검색 결과에서 관찰 가능한 것부터 확장한다.

후보:

1. 입력 키워드 기반 확장 키워드 생성
2. 상위글 제목에서 자주 나오는 단어 추출
3. 지역/상황/목적 조합 키워드 제안
4. 키워드별 상위 블로그 글 수와 대상 블로그 현재 순위 비교

예:

```text
기준 키워드: 서촌 카페

후보:
- 서촌 조용한 카페
- 서촌 데이트 카페
- 서촌 주차 카페
- 서촌 애견동반 카페
- 서촌 디저트 카페
```

### 4. 상위글 제목 분석 고도화

특정 키워드의 상위 블로그 제목을 보고 자주 보이는 단어를 표시하는 MVP는 구현됐다.

다음 단계는 공통 패턴을 더 실용적으로 요약하는 것이다.

예:

```text
키워드: 서촌 카페

상위글 제목에 자주 보이는 말:
- 후기
- 데이트
- 주차
- 메뉴
- 예약
- 분위기
```

사용 목적:

1. 글 제목 아이디어
2. 본문에 빠뜨리면 안 되는 정보 확인
3. 검색 의도 파악

주의:

상위글을 그대로 베끼는 기능이 아니다. 독자가 궁금해하는 요소를 놓치지 않도록 돕는 기능이다.

### 5. 발행 전 분석 고도화

발행 전 본문 분석 코치 MVP는 구현됐고, 상위글 제목/요약과 가져온 내 글 DB도 연결됐다. 다음 단계는 사진 체크리스트와 글별 차별화 가이드를 더 구체화하는 것이다.

예:

```text
상위 글 제목에는 주차와 예약 정보가 자주 보입니다.
내 기존 글 "서촌 데이트 코스"를 내부 링크 후보로 연결할 수 있습니다.
이미 "서촌 카페" 목표 키워드 글이 있으니 이번 글은 조용한 좌석과 신상 메뉴 중심으로 차별화하세요.
사진 체크리스트에 메뉴판과 외관 사진이 빠져 있습니다.
```

주의:

이 기능은 네이버 공식 품질 점수가 아니라 내부 프록시 점수이며, 상위글을 베끼기보다 독자가 기대하는 정보를 빠뜨리지 않게 돕는다.

### 6. 발행 캘린더

관심 키워드와 글 소재를 발행 일정으로 관리한다.

상태:

```text
아이디어
작성 중
발행 완료
순위 확인 중
수정 필요
```

목표:

가족가 “뭘 써야 하지?”를 줄이고, 이미 정한 소재를 편하게 관리하게 한다.

### 7. 앱 안 알림 고도화

Web Push 전 단계인 앱 안 새 소식 섹션은 구현됐다.

다음 단계는 알림을 더 정확하게 선별하고 저장하는 것이다.

예:

```text
오늘의 새 소식
- 서촌 카페: 모바일 블로그탭 3위 진입
- 다낭 동마켓: PC 통합검색 순위권 밖
- 호텔파리칠: PC 블로그탭 1위 유지
```

나중에 이 데이터를 Web Push로 보낸다.

추가 개선:

1. 알림 읽음 처리
2. 알림 저장 테이블
3. 알림 조건 설정
4. 글별 키워드 알림 포함

### 8. Web Push 알림

서버 배포와 HTTPS 이후 구현한다.

필요 조건:

1. HTTPS
2. Service Worker
3. 홈 화면에 추가된 PWA
4. 사용자가 직접 알림 허용
5. 서버에 push subscription 저장

초기 알림 조건:

```text
관심 키워드가 30위 안에 새로 들어오면 알림
관심 키워드가 5계단 이상 오르면 알림
관심 키워드가 순위권 밖으로 떨어지면 알림
```

## 외부 도구 참고

블로그 운영자들이 많이 참고하는 도구 유형:

1. 네이버 데이터랩: 검색어 트렌드와 쇼핑 인사이트 확인
2. 네이버 광고 키워드도구: 광고 관점의 키워드 수요 확인
3. 블랙키위, 키워드마스터, 판다랭크, 웨어이즈포스트류: 키워드 분석, 경쟁도, 순위 추적 참고

이 프로젝트는 우선 외부 도구를 대체하기보다, 가족 블로그에 필요한 관찰과 실행을 편하게 만드는 데 집중한다.
