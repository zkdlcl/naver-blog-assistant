# BMS v1.0.0 Release

## 의미

`v1.0.0`은 이 프로젝트가 개인용 로컬 블로그 운영 도구로 일상 사용 가능한 상태에 도달했다는 뜻이다.

현재 버전에서 가능한 것:

1. 네이버 키워드 순위 확인
2. surface별 상위글 조회
3. 관심 키워드와 이력 저장
4. 내 블로그 공개 글 가져오기
5. 글별 목표 키워드 관리
6. 발행 전 본문 분석
7. 외부 AI 보강 분석
8. 선택적 Discord 봇 원격 확인
9. 노트북/PC 로컬 운영과 watch-ranker 포함 자동 시작

## 운영 기준

v1.0.0은 아래 기준을 전제로 한다.

1. 제품 대상은 한 명의 네이버 블로그 운영자다.
2. 주 저장소는 로컬 SQLite(`data/bms.sqlite3`)다.
3. 코드 동기화와 데이터 동기화는 분리한다.
4. 동시에 여러 장비를 메인 DB처럼 쓰지 않는다.

## 새 노트북 이전 최소 체크리스트

1. 저장소 clone
2. `bash scripts/bootstrap_local.sh`
3. `.env` 작성 또는 기존 `.env` 복사
4. 기존 PC의 `data/bms.sqlite3` 복사
5. `bash scripts/start_local_services.sh`

## 포함하지 않은 것

v1.0.0에서 일부러 미룬 것:

1. 다중 장비 DB 자동 동기화
2. 상시 클라우드 운영 표준화
3. Web Push
4. 발행 캘린더
5. 알림/캘린더 고도화

## 검증 기준

릴리즈 마감 확인 명령:

```bash
source venv/bin/activate
pytest
```
