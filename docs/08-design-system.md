# 디자인 시스템

## 제품 인상

가족가 아이폰 홈 화면에서 여는 개인 블로그 스튜디오.

느낌:

1. 관리 도구지만 차갑지 않다.
2. 블로그 운영 성과가 한눈에 들어온다.
3. 매일 열어봐도 부담이 없다.
4. 기본 관리자 화면이나 투두앱처럼 보이지 않는다.
5. 핑크 톤이지만 유아틱하지 않고 iOS 앱처럼 단정하다.

## 화면 원칙

### 첫 화면

첫 화면은 랜딩 페이지가 아니다.

앱을 열자마자 바로 할 수 있어야 한다.

```text
키워드 입력
순위 확인
PC/모바일 결과
최근 이력
```

### 정보 위계

가장 중요한 정보:

```text
몇 위인가
```

그 다음:

```text
PC인지 모바일인지
어떤 글인지
글 URL
최근 이력
```

따라서 결과 카드에서 순위 숫자는 크게, 표면 이름은 작게 둔다.

## 레퍼런스 방향

사용자 제공 레퍼런스:

1. Figma Lo-fi Wireframe Kit
2. Figma iOS App Wireframes
3. Mobbin iOS screen reference

해석:

1. lo-fi 와이어프레임처럼 정보 구조는 단순하게 유지한다.
2. iOS 앱처럼 여백, 카드, 큰 타이틀을 사용한다.
3. 기능형 대시보드가 아니라 러블리한 개인 스튜디오 앱처럼 보이게 한다.

## 시각 방향

### 팔레트

주 색상:

```text
Rose Pink: #db5f87
Deep Rose: #a83e63
```

보조 색상:

```text
Soft Pink: #ffe8f0
Petal: #fff2f6
Fresh Mint: #4b9b86
Warm Gold: #e5b84c
Coral Alert: #df6b59
```

배경:

```text
Fresh White: #ffffff
Soft Pink Wash: #fff7fa
```

금지:

1. 보라/남보라 그라데이션
2. 베이지/크림/샌드/브라운 위주 팔레트
3. 다크 블루/슬레이트 위주 관리자 화면
4. 둥근 오브 장식
5. 핑크 단색만 반복하는 one-note 화면

## 컴포넌트

### Command Panel

키워드 입력의 중심 영역.

기능:

1. 입력
2. 실행
3. 확인 범위 표시

시각:

1. 로즈 핑크 배경
2. 앱 아이콘 이미지
3. 짧은 설명
4. 안정적인 버튼 크기

### Rank Ticket

PC/모바일 결과 카드.

상태:

```text
found
missing
loading
```

정보:

1. 표면 이름
2. 순위
3. 글 제목
4. 글 URL

### History Timeline

최근 저장 이력.

목표:

1. 같은 키워드의 최근 확인 상태를 빠르게 본다.
2. PC/모바일을 작은 배지로 나눠 보여준다.

## 모션

모션은 기능을 방해하지 않는다.

사용:

1. 조회 중 progress bar
2. skeleton shimmer
3. 결과 카드 rise-in

금지:

1. 계속 움직이는 장식 배경
2. 과한 튕김 효과
3. 레이아웃이 흔들리는 hover/active 효과

## iPhone 기준

주요 viewport:

```text
390 x 844
430 x 932
```

조건:

1. 버튼 높이 44px 이상
2. 입력창 높이 44px 이상
3. 긴 블로그 제목은 줄바꿈
4. 긴 URL은 줄바꿈
5. 텍스트가 부모 밖으로 넘치지 않음
